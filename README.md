# 한입 복습 · 식생활과 건강

2026년 식생활과 건강 중간고사 족보 30문항과 1~5강 기반 예상문제 100문항을 공부하는 정적 웹사이트입니다. GitHub Pages에서 빌드 과정 없이 실행됩니다.

- **족보학습**: 기존 족보 30문항만 수록 (`#practice`)
- **강의자료 예상문제**: 별도 제작한 100문항, 1~5강 필터 (`#lecture`)
- 오답노트·정답/해설: 족보·예상문제·전체 범위를 선택
- 문제집별 진도·정답률, 해설에 강의·PDF 페이지 번호 표시
- 기존 localStorage v1의 족보 ID와 기록을 유지하며 예상문제에는 101~200 ID를 사용

- O/X·객관식 즉시 채점, 복수선택·단답형 채점
- 문항별 정답·해설, 출처와 원문/복원 내역
- 현재 오답 및 한 번이라도 틀린 문제 모아보기, 다시 풀기
- 주제·풀이 상태·검색, 북마크, 순서 섞기
- localStorage에 학습 기록 유지, 보관용 JSON 내려받기, 초기화
- 모바일 레이아웃 및 키보드 탐색

## 실행

프로젝트 폴더에서 `python -m http.server 4173 --bind 127.0.0.1` 실행 후 <http://127.0.0.1:4173>을 엽니다. 별도 패키지 설치가 필요 없습니다. Google Fonts가 불러와지지 않아도 시스템 글꼴로 동작합니다.

## 문제와 답안

`questions.js`는 족보 문항, `lecture-questions.js`는 예상문항, `question-banks.js`는 문제집 구분과 진도 범위, `core.js`는 채점·저장 검증, `app.js`는 화면 동작입니다. 학습 기록은 이 브라우저에만 저장되며 기기 간 동기화되지 않습니다. 초기화는 두 문제집의 기록을 모두 지웁니다. JSON 내려받기는 보관용이며 가져오기 기능은 없습니다.

제공된 족보 PDF의 1~7쪽 30문항 및 2026년 강의자료 1·2강 합본 31쪽, 3강 36쪽, 4강 48쪽, 5강 35쪽을 참고했습니다. 예상문제는 강의별 10·10·25·35·20문항이며 각 해설에 PDF 페이지 기준의 근거를 표시합니다. 2강의 페이지도 1·2강 합본의 PDF 번호입니다. 원본 PDF와 개인 폴더 경로는 저장소에 올리지 않았습니다. 정답은 학습용 해설이며 실제 출제를 보장하지 않습니다.

12·13·16·26번은 누락 보기를 복원했고, 27번은 복수선택, 28번은 객관식으로 재구성했습니다. 17번은 강의자료의 2020년 OECD 암 발생률 비교로 범위를 한정했습니다. 18번은 근거가 불명확한 일괄적 “위험 두 배” 표현을 제외하고, 29번은 “지방산”을 “중성지방”으로 보정했습니다. 3·4·24·25번 등도 강의 기준을 명확히 했습니다. 원문과 보정의 차이는 각 문항 해설에서 확인할 수 있습니다. 미복원 원문의 공식 답안을 확정하는 자료가 아닙니다.

보충 출처는 NIH ODS, NIDDK, NCCIH, NHLBI 및 미국심장협회이며 각 해설과 사이트 자료 안내에서 직접 링크합니다. 그 외 문항은 기초 영양학 개념 설명입니다. 제작일: 2026-10-19.

## 검증

`node --test tests/*.test.cjs` — 문항 무결성과 출처 범위, 채점, 오답 누적, 문제집 구분, 진도 격리, 기존 기록 호환과 저장 데이터 복원을 확인합니다.

## GitHub Pages

저장소 Settings → Pages에서 `Deploy from a branch`, `main`, `/ (root)`를 선택합니다. 모든 자원 경로는 프로젝트 하위 경로 배포를 지원하는 상대 경로입니다.
